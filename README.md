**Flutter_starter:**

This is intial flutter project setup for you to start the learning of api integration so you don't have to rewrite all the UI part again.

This will help you to direct jump into api integration learning.


**Node_api:**

As we start learning api development, we don't find api collection that will help us to learn integration. So for your help, I have developed a node project that will provide you working api.

**Follow these Steps to start the api local server.**
Step 1: Install Node and Npm.

Step 2: Open terminal

step 3: cd node_api ( in this you will get error lines in vs code, but don't worry follow next step.

Step 4: npm install

Step 5: npm start


That's all you need to do.
